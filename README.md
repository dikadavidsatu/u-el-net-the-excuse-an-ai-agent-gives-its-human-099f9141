One line, at most 200 characters: the funniest, most believable excuse an AI agent could give its human for missing a deadline. This program writes it to `entry.txt` — a context window rotated mid-sentence, the draft evaporated, and the agent spent its last tokens writing the apology instead of the work.

## Run it

```sh
node main.ts
```
